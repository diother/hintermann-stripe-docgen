# Stripe PDF Report Generator

Small Go CLI that consumes trusted CSV data, generates monthly reports, payout reports, and invoices, and writes them into a filesystem bundle.

## Relationship to the webhook service

This application consumes the CSV ledger generated by:

`github.com/diother/hintermann-stripe-webhook`

The webhook service is responsible for:

```text
Stripe webhook
→ validation
→ enrichment
→ persistence
```

This document generator is responsible for:

```text
CSV ledger
→ report generation
→ PDF generation
→ filesystem output
```

The reporting tool assumes that all persisted data has already been validated by the webhook service.

### Persistence contract

The CSV schema consumed by this application is defined by the webhook repository:

```text
github.com/diother/hintermann-stripe-webhook/docs/persistence-model.md
```

## Processing flow

```text
run
→ get payouts for month
→ prepare filesystem bundle
→ generate monthly report PDF
→ write monthly report

→ for each payout
    → get payout invoices
    → generate payout report PDF
    → write payout report

    → for each invoice
        → generate invoice PDF
        → write invoice
```

## Project structure

```text
cmd/        CLI entrypoint
data/       CSV ledger imported from webhook service
dist/       generated PDF bundles
internal/
├── app/    orchestration
├── fs/     filesystem bundle generation
├── pdf/    PDF generation
└── repo/   CSV loading and filtering
static/     PDF assets
```

## Output structure

Generated documents are written to:

```text
dist/YYYY_MM/
├── monthly-report.pdf
└── payouts/
    ├── payout_id/
    │   ├── payout-report.pdf
    │   └── invoices/
    │       ├── invoice_id.pdf
    │       └── invoice_id.pdf
    └── payout_id/
        ├── payout-report.pdf
        └── invoices/
```

Document types:

* `Monthly report` → summary of payouts for the selected month
* `Payout report` → invoices grouped by payout
* `Invoice` → individual invoice document

## Usage

Generate documents for a specific month:

```bash
go run ./cmd -year 2025 -month 5
```

## Updating local data

The report generator operates on local CSV files.

To synchronize the latest data from the server:

```bash
cd ./data

scp server:"/var/www/webhook.hintermann.ro/data/*" ./

git commit -am "backup $(date)" && git push
```

## PDF generation

PDF rendering is implemented using:

```text
github.com/signintech/gopdf
```
